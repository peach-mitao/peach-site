参考入口：[Cloudflare Dashboards](https://dash.cloudflare.com/)。取证日期：2026-10-23。

## 实现边界

Peach 补充页采用相同的信息密度、深色中性卡片、蓝色数据强调、顶部筛选与卡片组织方式。
控件直接使用 Cloudflare 官方 [Kumo](https://github.com/cloudflare/kumo) 2.15.0（MIT）的 Select、按钮样式及 standalone CSS；浮层定位、键盘与焦点由其 Base UI 实现管理。
主题使用 `data-mode="dark"`、`data-theme="kumo"`，卡片和边框引用 Kumo 原始颜色 token。
字体复用官网已有 Inter 可变字体文件，声明 100–900 字重范围，并使用实测字形特性；字体文件与 Cloudflare 在线分发的文件未做字节一致性声明。
补充页保留 Peach 名称和三个分析标签，不复制 Cloudflare 的账户菜单或标志。功能图标使用 Kumo 同依赖的 Phosphor。
手机将侧栏压缩为品牌栏，筛选项自动折行，图表改为单列。

## 对齐范围

控件、菜单、字形、字距、按钮、卡片、侧栏、表格字号与间距逐项核对。自有容器使用独立的 `analytics-grid` 类，避免覆盖 Kumo 的通用 `grid` 工具类。
下拉组件按用途保留真实选项；时间范围仅支持采集保留期内的既定选项，不添加无效的原生日历入口。
视觉核对覆盖下拉展开、热力图、访问动线和会话明细的桌面与 390×844 手机布局。空库预览不伪造访问数；有数据时的表格行与错误恢复由行为回归验证。

“页面版本”指维护者构建时保存的页面截图。默认选择最新匹配截图，历史选项按日期、页面、设备与语言展示；它不代表访客页面录像。
