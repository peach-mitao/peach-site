# Peach 官网

Peach 的产品官网。Peach 是本地优先的影片刮削与媒体管理工具。

[官网](https://peach.video/) · [在线演示](https://demo.peach.video/) · [下载](https://github.com/peach-mitao/peach/releases) · [English](README.md)

[![CI](https://img.shields.io/github/actions/workflow/status/peach-mitao/peach-site/check.yml?branch=main&label=CI&logo=githubactions&logoColor=white)](https://github.com/peach-mitao/peach-site/actions/workflows/check.yml)
[![License](https://img.shields.io/badge/license-AGPL--3.0--only-blue?logo=gnu&logoColor=white)](LICENSE)

## 功能

- **产品导览**：中英文介绍、应用截图与交互示意。
- **下载入口**：Windows 安装版与免安装版、Mac ARM 与 Intel 包，以及 Docker 和源码运行指南。
- **备用下载**：同版本优先 GitHub；两边的版本、文件名、大小和 SHA-256 一致时显示 R2 备用链接。
- **文案编辑**：通过 Peach 共用编辑器在本地修改官网文字。

截图使用普通电影演示资料，来源与许可见[素材说明](https://peach.video/credits/)。
