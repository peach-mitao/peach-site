# Peach 独立支持页样式来源

取证对象是 Peach 应用的生产错误页，不存在生产 DMCA 页面。版权投诉页仅复用该页面的字体、颜色、卡片与表单控件样式，投诉正文与邮件整理由官网维护。

生产页面通过项目 CA 严格校验 HTTPS 取得。浏览器读取了当前页面 DOM 与 computed style；独立截图接口超时后，使用现有 Playwright 留存页面画面。私有主机坐标、原始响应和截图保存在仓库外。

| 元素 | 当前样式 |
| --- | --- |
| 页面 | 居中内容，桌面水平 24px、垂直 48px 留白 |
| 错误卡片 | 最大宽 560px、24px 圆角、32px 内边距、24px 内容间距 |
| 手机卡片 | 水平 16px、垂直 24px 页面留白，20px 卡片内边距 |
| 标志 | 40 × 40px，下方 16px 间距 |
| 标题 | 20px / 26px，500 字重 |
| 按钮 | 36px 高，10px 圆角，14px / 20px，500 字重；共享渐变与焦点环 |
| 字体 | Inter Variable；汉字由系统字体回退 |

版权投诉正文较长，容器使用 760px 最大宽度。输入框使用共享颜色与 36px 高度，移动端输入字号为 16px；多行输入允许垂直调整。

同步入口为 `scripts/sync_support_ui.ts`；`support-ui-source.json` 锁定应用提交和每项资源的 SHA-256。样式文件摘要为 `2cecc0e4764487fcb9a648a68ef6dfbd4da51b543848cc02bcdf291fa8538246`，与取证时的生产响应一致。应用样式变动需要重新同步与查看预览，不把旧快照称作当前生产状态。

官网 `/copyright/` 与 `/en/copyright/` 为静态语言版本。独立 404 使用共用 TypeScript 解析显式参数、版本地址、已保存选择及浏览器语言，只显示一个语言。演示站的支持页资源放在 `/assets/support-ui/`，避开应用的 `/assets/:id` 页面路由。
