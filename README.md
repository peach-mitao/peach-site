# Peach Website

The product website for Peach, a local-first video metadata scraper and media manager.

[Website](https://peach.video/) · [Live demo](https://demo.peach.video/) · [Download](https://github.com/peach-mitao/peach/releases) · [简体中文](README.zh-CN.md)

[![CI](https://img.shields.io/github/actions/workflow/status/peach-mitao/peach-site/check.yml?branch=main&label=CI&logo=githubactions&logoColor=white)](https://github.com/peach-mitao/peach-site/actions/workflows/check.yml)
[![License](https://img.shields.io/badge/license-AGPL--3.0--only-blue?logo=gnu&logoColor=white)](LICENSE)

## Features

- **Product tour**: Chinese and English pages with application screenshots and interactive examples.
- **Downloads**: Windows installer and portable builds, Apple silicon and Intel Mac packages, and Docker and source setup guides.
- **Backup downloads**: GitHub is the primary source; R2 links appear when the same version, filename, size and SHA-256 match.
- **Copy editing**: edit website text locally with the shared Peach editor.

Screenshots use ordinary movie demo data. See [asset credits and licenses](https://peach.video/en/credits/).
