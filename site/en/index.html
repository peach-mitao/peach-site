FAQCan't find an answer? Contact the developer on X or Telegram

Will Peach change my files?

Scanning and filling in metadata leave your original files unchanged. Manual organization renames or moves files; emptying the trash deletes files, and cleanup during resource sync removes empty folders. These file changes require confirmation.

Which cloud drives does Peach support?

Drives mounted as local folders through tools such as CloudDrive2; see cloud drive mounts. Cloud downloads depend on what each provider currently supports; sign-in tokens are stored locally.

How do I use Peach on other devices?

During initial setup, allow access from devices on the same local network. Connect your other device, such as a phone, to that network, open the address shown in Settings and set an access password.

Where does Peach store its data?

In the local peach-data folder. The default location on Windows is %LOCALAPPDATA%\Peach\peach-data, and on macOS it is ~/Library/Application Support/Peach/peach-data.

Which languages does Peach support?

Peach's interface is currently available only in Chinese. Support for English and other languages is in progress. Contact the developer if you would like to help with translation.

My Mac says “Peach” is damaged and can’t be opened

Test builds are not notarized by Apple yet. Run a command in Terminal to remove the quarantine attribute from Peach before opening it; run the command again after installing a new version.

Open Peach on your Mac

  1. Open the downloaded DMG and drag Peach into the Applications folder.
  2. Open Terminal, paste the command below and press Return. When prompted, enter your Mac login password; nothing appears on screen as you type.
    zsh
    sudo /usr/bin/xattr -rd com.apple.quarantine "/Applications/Peach.app"
  3. Double-click Peach in Applications to open it.

Test builds are not notarized by Apple yet. Apps downloaded from the internet carry a quarantine attribute, so macOS reports “Peach” is damaged and can’t be opened. This command removes the quarantine attribute from Peach only; run it again after installing a new version.
