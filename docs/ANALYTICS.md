# 访问分析

官网和演示站共用 Cloudflare 数据链路。网络与资源用量保留在 Cloudflare 原生面板；“点击与动线”补充页展示点击位置、可见页面点击率、跨站路径和会话时间线。

## 展示与数据

| 入口 | 数据来源 | 适用问题 |
| --- | --- | --- |
| CF 原生面板、SQL API | HTTP 请求、Workers 指标、Analytics Engine 聚合 | 哪个网站用量高、缓存命中率、请求国家、既有自定义事件趋势 |
| `/analytics/` | Basin SQL 查询私有 R2 日志表，D1 布局元数据，私有 R2 构建截图 | 点击哪里、区域可见后是否点击、从哪里进入、两站之间如何流转、最后停在哪里 |
| `/privacy/analytics` | 第一方统计偏好 | 停止或恢复当前浏览器的自有统计 |

HTTP 请求包含图片、缓存校验和自动化访问，不等于页面访问人数。Analytics Engine 可以抽样；精确事件使用 Basin Pipelines 的 Worker Stream 绑定写入私有 R2 的 Iceberg／Parquet 表，不抽样。事件 ID 用于查询去重，时间、序号、视图和会话字段用于重建序列。D1 只保存布局等少量元数据，不保存访问事件或逐事件去重索引。

原生面板沿用已有配置。补充页外观依据[实测记录](reference-snapshots/cloudflare-dashboard.md)实现，Worker 分别查询 Basin SQL 事件表和 D1 布局元数据。

## 会话与隐私

浏览器使用随机匿名会话值，第一方 Cookie `peach_visit` 在两站共享，30 分钟无活动后更换。该值不用于登录或识别真实身份。事件包含规范页面路径、功能标识、设备类别、语言、可见时长和点击位置；动态实体路径归一为 `:id`。

自有统计不记录页面文本、输入内容、搜索词、完整 URL、完整浏览器标识或 IP。收集端仅临时使用连接 IP 执行限流，不把它写入事件。`?edit` 和截图生成模式不采集，识别到的机器人跳过；这些规则不能保证消除全部机器人或阻止伪造事件。

点击和曝光按页面视图汇总。曝光需要区域至少 50% 可见并持续 1 秒；点击本身也作为该页面可见的证据。重复卡片按功能汇总点击率，位置图保留卡片序号。大量尺寸、内容排列变化可能改变实际卡片位置，截图只代表登记的构建和状态，不是访客 DOM 回放。

事件按最多 40 条一批发送。队列有上限，仅在有待发送事件时设置刷新计时；不持续轮询、不持久化失败队列、不自动重试。页面隐藏或离开时尽力发送；浏览器崩溃、断网、拦截器和后台冻结都可能丢失末尾事件。因此“最后停留”是最后观察到的位置，不保证是实际关闭位置；最近 30 分钟仍有活动的会话不计为已结束。

原始行为事件、对应参考图和布局元数据长期保留，不运行到期删除任务。Stream 使用结构化协议校验，HTTP 公开写入端点关闭，采集端等待原生持久接收后才返回成功。Sink 使用 zstd Parquet，按 100 MB 或 300 秒合并落盘；最新明细存在落盘延迟。Basin SQL 使用仅限日志桶的只读 API Token，通过 Worker Secret 提供，只执行服务端查询模板。布局列表不携带元素边界全集，热力图按选中布局单独读取。Cloudflare Web Analytics 是独立的平台统计；统计偏好页说明其范围。

报表已完成结果按授权断言、站点和筛选条件散列后，在私有参考图桶的 `reports/v1/` 前缀复用 30 分钟；Worker 内存只保存已完成字符串。R2 条件写租约限制同一报表的并发生成，生成中的请求返回 503 和重试间隔，不自动重试 SQL；缓存存储故障时拒绝查询，避免放大扫描。该前缀使用两天的对象生命周期，当前参考图不受影响。页面显示结果生成时间；会话明细独立分页读取。

事件查询同时使用事件时间和入库时间下界，后者预留采集协议允许的五分钟时钟偏差，保留迟到写入并利用日期分区。历史导入的入库时间晚于事件时间。查询只选择报表所需列，分区过滤不替代事件时间筛选与事件 ID 去重。

Catalog 每小时检查文件整理，目标大小为 128 MB；过期快照保留 7 天且至少保留 2 份。快照清理仅回收被替代的表版本和文件，不删除当前表中的历史事件。报表按事件 ID 统计，原生管道重复交付不会增加访问和点击计数；会话明细按所选时间范围分页读取。

## UI 改版与监控同步

1. 相同功能保留稳定标识，例如 `download.windows`；仅改文字、颜色或位置时不更名。改变业务语义时新增标识，避免混算。
2. 官网在 `browser/assets/behavior-rules.ts` 维护规则；演示站在 `browser/behavior-rules.ts` 维护规则。优先使用语义属性和控件用途；没有语义属性的部分按钮使用有限的静态文案匹配，修改文案时必须同步规则并通过覆盖检查。匹配文案不会写入访客事件，不以动态实体名称生成标识。
3. 两站通过构建指纹区分页面版本。发布前从本地构建生成桌面和手机截图、元素边界和覆盖清单。发布门槛检查指纹、所有登记路由、图片哈希和未映射控件。
4. 默认展示最新匹配截图；历史截图和点击按页面、版本、设备、语言、状态对应，禁止将不同版本的点叠到一张图上。
5. 新增路由、弹窗、条件按钮或主题状态时，一并登记捕获场景并补对应行为回归。仅扫描路由初始状态不能覆盖尚未打开的弹窗；运行时的未映射点击用于发现遗漏，不替代发布前场景检查。

官网是共享协议、采集核心和产物检查器的规范来源。演示站通过 `scripts/sync_behavior.ts` 同步指定官网源码，`behavior-source.json` 记录提交和哈希；允许草稿预览，发布拒绝草稿来源及副本漂移。UI 本身仍分别维护。

## 维护入口

- 构建浏览器资源：`npm run browser:build`。
- 启动本地分析与文字编辑预览：`npm run dev:behavior`。预览使用独立空数据库，不连接生产访问事件。
- 官网截图入口 `npm run behavior:capture -- <本地预览地址>` 覆盖中英文页面、三个下载平台与 Mac 打开步骤。通用 `scripts/capture_behavior.ts` 接收本地预览地址和路由 JSON 文件，也支持带 `route`、`click` 选择器列表的场景；仅允许本地地址。
- 发布前契约检查：`npm run behavior:check`。`PEACH_BEHAVIOR_ARTIFACTS` 可指定产物目录。
- 采集链路浏览器回归：`npm run test:behavior`，使用临时数据库核验采集、隐私、会话和补充页。
- 发布截图与元数据：`scripts/publish_behavior.ts` 接收产物目录、`site` 或 `demo`、当前构建指纹三个参数。先通过契约检查，再上传私有 R2、校验图片回读并分批登记和核对 D1；不插入访问事件。
- 参考图发布使用四路网络队列，先回读已有对象，正文哈希匹配即可复用，只有缺失对象才上传。失败后停止启动新对象，等待在途操作结束再返回错误；全部对象核对完成才登记 D1。并发不增加对象调用次数。临时网络错误与 429、500、502、503、504 按 2、4、6、8 秒最多重试四次；权限和正文哈希错误直接拒绝，D1 登记仍逐行回读核对。
- Worker 绑定原生 Stream、只读查询凭据、D1 元数据、私有 R2 参考图、限流器与 Access 应用签发者、AUD。分析页、图片和查询均检查 Access JWT；仅本机预览允许独立的回环地址豁免。生产采集缺失 Stream 时返回不可用，禁止回退到 D1 事件写入。本地预览使用独立 SQLite 测试数据库。
- `PEACH_CF_DASHBOARD_URL` 在构建时配置维护者的 CF 原生面板链接；未配置时打开 Cloudflare 控制台首页。链接只允许 Cloudflare 控制台域名，私人面板地址不写入页面源码。

界面预览经确认后再执行项目测试和部署门槛。产品页面继续由静态资源层提供；行为采集增加独立批量端点，不让全部图片、视频进入 Worker。

参考图最多截取页面前 16000 CSS 像素，沉浸播放页仅截取当前视口，避免无限滚动页面持续加载。超出参考图或缺少匹配元素的点击不叠加，并显示遗漏数量；区域点击汇总仍使用全部匹配事件。

平台能力依据：[自定义面板](https://developers.cloudflare.com/analytics/custom-dashboards/)、[SQL API 数据集](https://developers.cloudflare.com/analytics/sql-api/datasets/)、[SQL 语法](https://developers.cloudflare.com/analytics/sql-api/sql-reference/)。
