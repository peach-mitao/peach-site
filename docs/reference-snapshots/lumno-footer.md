# Lumno 页脚布局观察

参考页面：[Lumno 官网](https://lumno.kubai.design/)，2026-10-24 取得当前 DOM、computed style 及桌面、手机画面。本记录是人工取证笔记，不登记为可变上游原文快照。

实测：页脚主区把品牌、安装入口、社交图标放在一侧，产品和支持链接分列放在另一侧；下方独立的信息行放版权和语言选择。桌面主区为两列 grid，64px 列间距，主要链接约14px，底部信息约13px。手机继续按用途分组，不把社交图标、隐私文字和语言名称连成同一排。

推导：分区和视觉层级承担不同入口的优先级；社交图标属于品牌联系，隐私与版权属于辅助信息，语言属于全站设置。分开位置比给所有入口增加同一种图标更能表达用途。

Peach 复用这些布局原则：品牌与社交为一组，版权投诉与统计偏好单独成组，语言选择进入底部信息行。颜色、品牌素材、内容与已有页面保持一致，不复制参考站的插画或安装渠道，不为填充列数增加多余链接。统计偏好页复用 Peach 支持页的生产样式与字体。

Ego 的 DOM/CSS 读取成功，截图接口返回 `CdpRequestTimeoutError: CDP request timed out: Page.captureScreenshot`。画面改用既有 Playwright 留存；原始响应、尺寸及截图在仓库外维护证据中保存。
